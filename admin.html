The CMS runs on local persistent storage synced with the public site. You can export a complete JSON snapshot or restore a previous backup anytime.

Developer Integration Notice

The data layer and analytics tracker are encapsulated inside cms-store.js. To replace localStorage with Firebase, Supabase, or PostgreSQL API endpoints, simply connect the store methods to your backend without modifying the admin UI controllers.
